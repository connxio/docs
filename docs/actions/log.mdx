# Log

The Log action writes a custom log entry at a specific point in the message flow. Use it to audit, debug, or trace messages as they pass through an integration.

## Configure the action

Add a Log action to your integration where you want to record a log entry and configure the settings below.

**Status**, **Description**, **Sender**, and **Receiver** support dynamic values using [CxMaL](../cxmal/connxio-macro-language.md). For example, use `{filename}` to include the message's file name or `{interchange}` to include its interchange ID.

## Log levels

| Level    | Value | Description                                 |
| -------- | ----- | ------------------------------------------- |
| Error    | 0     | Only errors are logged                      |
| Minimum  | 1     | Minimal logging                             |
| Standard | 2     | Default level — general operational logging |
| Verbose  | 3     | Detailed logging for diagnostics            |
| Off      | 4     | No logging                                  |

:::info
The log entry will only appear if the log level configured here is equal to or below the log level configured on the integration's logging webhook. Setting the level to `Off` effectively suppresses this log entry entirely.
:::

See [Logging](../integrations/logging.md) for integration logging configuration and log providers.
