# GraphQL

The GraphQL trigger calls a GraphQL endpoint on a schedule and makes the response content available to subsequent actions. Use it to retrieve data with a query or execute a mutation.

## Configure the trigger

Add a GraphQL trigger to your integration and configure the endpoint, query, and settings below.

## Schema introspection

If the endpoint supports schema introspection, Connxio can fetch its schema to provide query validation and autocompletion in the editor. The schema status appears beside **Query**.
