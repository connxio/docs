# Redirect

The Redirect action sends a message to another integration within Connxio. Use it to route messages between integrations or reuse a shared processing flow.

## Configure the action

Add a Redirect action to your integration and select the integration that should receive the message. Choose whether to preserve the original interchange ID.

:::caution Circular redirects
Connxio allows circular redirects, where a message is routed back to an integration it has already passed through. These can cause infinite processing loops that count toward subscription usage and affect billing costs. Check the complete redirect flow to avoid unintended loops.
:::
