# API keys

API keys connect applications to the Connxio Messaging and Management APIs. Each key belongs to a subscription and has scopes that determine which API functions it can access.

Use **API keys** in the portal to create keys, review their scopes, reveal their values, and enable or disable access.

## Create an API key {#creating-an-api-key}

1. Open **API keys** and select **Create API key**.
2. Enter a **Name** that identifies the application or purpose of the key.
3. Select the required **Scopes**. Select **Messaging** to make the **Webhook** option available.
4. Choose the **Subscription** the key will access.
5. Select **Create**, or **Cancel** to close the dialog without creating a key.

## Scopes

Choose scopes according to the operations the calling application needs. A key can have multiple scopes.

| Option | Scope shown in the key list | Access |
| --- | --- | --- |
| Messaging | `Messaging.All` | Use the Messaging API to send messages to Connxio. |
| Webhook | `Messaging.Webhook` | Allow messaging requests without an OAuth token when the webhook header is supplied. Available under Messaging. |
| Management | `Management.All` | Manage resources such as integrations, security configurations, and code components through the Management API. |

Keys generated for a [Custom API](./custom-api.md#api-key) appear with a **Custom API** badge and the `Messaging.Dynamic` scope. They can also have `Messaging.Webhook` enabled. These keys are associated with their custom API rather than created through the scope options above.

## Review and reveal keys

Each entry in **API keys** shows its name, subscription, and scope badges. Select **Reveal key** to view the key value and copy it for use by your application.

Custom API entries also provide a navigation button to open the related API. See [Custom API](./custom-api.md) for its configuration and key settings.

## Use an API key {#using-api-keys}

Include the key in the `Connxio-Api-Key` request header. Follow the [API authentication reference](/reference/connxio-api) for the other headers and authentication requirements of the endpoint you are calling.

### Webhook requests

For a key with the **Webhook** scope, include both headers to use webhook authentication:

```http
Connxio-Api-Key: YOUR_API_KEY
Connxio-Api-Webhook: true
```

Webhook authentication allows the request without an OAuth token. Enable this scope only when the caller needs that authentication method.

## Disable an API key {#disabling-api-keys}

Use the enable/disable control on the key's entry to change whether it is active. Disabling a key stops applications using it from accessing the API with that key. You can enable it again when access is needed.

## Delete an API key

For a key with a delete control, select the **trash icon** on its entry to delete it. Update any applications using the key before removing it.

For a **Custom API** key, open the related API to manage its key and lifecycle. See [Custom API key settings](./custom-api.md#api-key).
